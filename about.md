## Regular Levels

Enter the level ID in **Level Slot X ID**, then set a keybind.  
Works in most menus.

**Note:** Does NOT work in certain menus like the Geode menu, level search menu, etc.


## Editor Levels

Enable **Show IDs in search** in the Editor Level ID API mod.  
Open the **My Levels** page and note the number in the top-right.

If the number is **3**, enter:

`e3`

into **Level Slot X ID**, then set the keybind.
